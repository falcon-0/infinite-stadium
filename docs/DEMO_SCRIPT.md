2. Rehearse actual UI transitions. Watch keeps audience, language and player choices inside the collapsed Viewing options drawer. Suggested questions, source dumps and a speed selector stay out of the fan view. Studio is a separate route.

3. Validate a freely worded question on the current model and record its actual response. Scorers, first passes, recent attacking activity and shot buildup are useful rehearsal topics, not product buttons.

4. Show playback advancing during the question. The answer must keep its original timestamp. Do not combine a response with an unrelated moment.

## Accurate claims



Instant play-by-play, compact context, animation and recorded recaps are deterministic. Azure open chat uses query planning, grounded answer writing and independent review. Supported comparisons and ordered endpoints use AI-interpreted typed operations with application-computed, application-rendered facts; other prose is model generated. The structured explanation flow also uses application wording. Provenance distinguishes these paths. None guarantees answers to every possible football question.



Twenty fixtures share five authored passage families. They differ in clubs, lineups, timings and routes, but are not twenty independent full-match simulations. The 2D display supplies no evidence of player intentions. An unrecorded incident is unobserved, not proof that it never happened.
